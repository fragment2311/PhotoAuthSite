# Журнал изменений PhotoAuthApp

В этом файле фиксируются все содержательные изменения проекта. Его необходимо
обновлять в той же правке, что и изменяемый код, конфигурация, документация,
контракт API, схема данных или развёртывание.

## Правила ведения

- Добавляйте новую запись в раздел `Unreleased` до передачи изменений на проверку.
- Описывайте результат для пользователя или системы, а не только имя файла.
- Для несовместимых изменений помечайте запись как **Breaking** и указывайте
  действие для обновления.
- Не включайте секреты, токены, пароли, персональные данные и содержимое `.env`.
- Косметические изменения без влияния на код, документацию или поведение можно
  не фиксировать.

Формат: разделы `Added`, `Changed`, `Fixed`, `Removed`, `Security`.

## Unreleased

### Added

- В админских настройках показываются доступные обновления PhotoAuthApp и список изменений; установку можно отменить или подтвердить.
- Добавлен внутренний Docker-агент обновления с проверкой запуска, отдельным подтверждением миграций и сохранением только схемы БД перед ними.

### Fixed

- Подготовлено production-развёртывание через существующий Docker Compose: внешний порт 27020, внешний MySQL и безопасный шаблон окружения.
- Добавлена текстовая инструкция DEPLOYMENT.txt для развёртывания на сервере.

- В разделе «Все проходы» фильтры и сортировка применяются ко всей выборке; отображение не ждёт синхронной генерации миниатюр.
- В больших папках галереи (включая CardNotFound) выводятся 60 фото на страницу, поэтому открытие не исчерпывает память сервера.
- Для фото из папки CardNotFound во «Всех проходах» выводится подпись «Карта не найдена». 
- Фильтры во «Всех проходах» отправляются на сервер кнопкой «Найти» и выбирают фото из всей базы, а не меняют порядок текущей страницы.

- Администратор снова может открыть журнал логов: проверка роли в маршрутах использует корректное имя роли.

### Removed

- Из журнала логов убрана временная кнопка создания тестовой ошибки.

### Added

- Добавлены единые документы назначения продукта и его архитектуры.
