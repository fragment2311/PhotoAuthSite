# PhotoAuthApp

## Назначение

PhotoAuthApp — корпоративное веб-приложение для контроля доступа. Оно помогает
сопоставлять события прохода с фотографиями, формировать отчёты по проходам и
рабочему времени, а также централизованно поддерживать конфигурацию устройств
системы контроля доступа (СКУД).

## Для кого

- Оператор — просматривает журнал проходов и фотографии.
- Администратор — управляет пользователями, локациями, контроллерами, камерами,
  парами устройств и настройками приложения.
- Внешний терминал или регистратор — получает через API активные пары устройств,
  настройки и учётные данные пользователей.

## Возможности

- Авторизация пользователей и разграничение доступа по ролям.
- Галерея фотографий из сетевого HTTP- или FTPS-хранилища.
- Поиск и просмотр проходов сотрудников.
- Расчёт рабочего времени и экспорт отчётов в Excel.
- Управление контроллерами, камерами, локациями и их логическими парами.
- API для внешнего оборудования с токеном доступа.
- Журналирование ошибок, аудит API-запросов и уведомления по email.
- Лицензирование установки и первичная настройка через веб-интерфейс.

## Границы системы

Приложение не получает события проходов непосредственно от оборудования и не
хранит сами фотографии как основной источник. Оно использует внешнюю MySQL как
источник данных СКУД и внешнее сетевое хранилище фотографий.

## Технологии

- PHP 8.2+ / Laravel 12.
- Blade и Vite для веб-интерфейса.
- MySQL для данных СКУД и служебных таблиц.
- Redis для кэша, сессий и блокировок.
- Docker: PHP 8.4 + Apache, публикация на порту 27017.
