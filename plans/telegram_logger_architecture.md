# Архитектура отправки ошибок в Telegram для PhotoAuthApp

## 1. Общая структура решения

### 1.1 Сервис TelegramLogger
Класс `App\Services\TelegramLogger` будет отвечать за отправку сообщений в Telegram бот.

#### Основные особенности:
- Использует HTTP клиент Laravel для отправки сообщений
- Поддерживает различные уровни ошибок (error, warning, info, critical, emergency)
- Автоматически добавляет информацию об окружении
- Имеет возможность фильтрации по уровням
- Обрабатывает ошибки отправки

### 1.2 Конфигурация
Добавим настройки в `config/services.php`:
```php
'telegram' => [
    'enabled' => env('TELEGRAM_ENABLED', false),
    'bot_token' => env('TELEGRAM_BOT_TOKEN', ''),
    'chat_id' => env('TELEGRAM_CHAT_ID', ''),
],
```

### 1.3 Переменные окружения
В `.env` добавим:
```
TELEGRAM_ENABLED=true
TELEGRAM_BOT_TOKEN=8340634038:AAE-Fkstk8zpfkk_bybwRHH4P5ivX6yQo4I
TELEGRAM_CHAT_ID=-1001234567890
```

## 2. Механизмы логирования

### 2.1 Расширение логгера
Создадим собственный логгер, который будет отправлять сообщения в Telegram при определенных условиях.

### 2.2 Фильтрация по уровням
- **Критические ошибки**: всегда отправляются
- **Ошибка**: отправляются при включенной функции
- **Предупреждения**: отправляются при включенной функции
- **Информационные**: отправляются при включенной функции

## 3. Точки отправки ошибок

### 3.1 Основные точки в коде
- `app/Services/LicenseService.php` - ошибки лицензирования
- `app/Http/Controllers/FtpAuthController.php` - ошибки FTP/HTTP
- `app/Services/AppSettingsFileStore.php` - ошибки работы с настройками
- `app/Http/Controllers/ThumbnailController.php` - ошибки генерации миниатюр
- `app/Console/Commands/GenerateThumbnails.php` - ошибки генерации миниатюр

### 3.2 Механизм отправки
В каждом месте, где происходит обработка ошибок, будет вызываться метод `TelegramLogger::send()` с соответствующими параметрами.

## 4. Реализация

### 4.1 Создание сервиса
Создать класс `App\Services\TelegramLogger` с методами:
- `send($message, $level, $context)` - основной метод отправки
- `formatMessage()` - форматирование сообщения для Telegram

### 4.2 Настройка конфигурации
Обновить `config/services.php` и `.env` файлы.

### 4.3 Интеграция с существующим кодом
Изменить существующие места обработки ошибок для использования нового сервиса.

## 5. Категоризация ошибок

### 5.1 Критические ошибки (EMERGENCY/ALERT)
- Ошибки инициализации приложения
- Недоступность базы данных
- Критические сбои в работе системы

### 5.2 Ошибки (ERROR)
- Сбои FTP/HTTP соединений
- Ошибки чтения/записи файлов
- Ошибки валидации данных

### 5.3 Предупреждения (WARNING)
- Деградация сервисов
- Частичные отказы
- Некритичные исключения

### 5.4 Информационные (INFO)
- Включение/отключение функционала
- Изменения конфигурации
- Завершение важных процессов
